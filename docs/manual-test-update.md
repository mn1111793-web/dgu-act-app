## Короткая первая проверка — приоритет сохранения

На вымышленной заявке ввести заказчика, длинный serial и несколько строк текста. Прокрутить форму до чеклиста/подписей и обратно. Нажать внутренний Назад, открыть тот же тип акта — поля должны восстановиться без DefaultLazyKey. Изменить текст, выполнить системный Назад и открыть снова. Повторить для всех трёх типов актов. Затем свернуть/вернуть и повернуть планшет, проверить те же значения. Эти Android-сценарии ещё **NOT RUN** агентом.

После этого: добавить три synthetic фото камерой/галереей; отдельно шильдик (например лист «А», не настоящий клиентский шильдик). Отказать в CAMERA, затем разрешить через обычный Android prompt/настройки приложения и повторить. Отменить один снимок — он не должен стать успешным фото. После успешного снимка/галереи Назад/reopen: фото и шильдик той же единицы. Проверить возвращение из камеры после поворота/пересоздания; автоматическое убийство процесса не требуется.

Карточка компании: synthetic PDF **с текстовым слоем** или DOCX, выбрать/отменить, посмотреть распознанное. Применение только отдельной кнопкой; пропуск не заменяет прежние реквизиты, пустые распознанные поля их не очищают. Старый DOC, OCR сканов/фото и ИНН API не поддерживаются. Лимит файла20МБ, XML DOCX8МБ. В форме сдачи из ремонта отдельной кнопки импорта/шильдика сейчас нет — реквизиты из заявки.

Подпись: нарисовать несколько длинных непрерывных штрихов (не только точки), убедиться, что штрих не обрывается; затем нарисовать без подтверждения → Назад/reopen; подтвердить → Назад/reopen; изменить содержание и убедиться в сбросе подтверждённых подписей. Записать акт; создать новую редакцию подписанного synthetic акта, убедиться, что предыдущая версия/фото остались. Для второй единицы свои поля/фото.

Последним создать настоящий PDF: полный длинный serial, все фото, страницы без наложений, А4 preview, отдельная тестовая папка и имя TEST_. Проверить отмену сохранения, share/печать только по желанию на безопасном тестовом документе. Печать на бумаге не обязательна. PDF/экспорт не backup базы. Визуальная проверка настоящего PDF и печать агентом **NOT RUN**.

## Ошибки, прежние черновики и возврат

Текст «Запись не подтверждена» не означает успех. При явной кнопке «Перечитать сохранённое» использовать её до повторных действий; ранее записанный акт может уже оказаться в списке. При ошибке черновика введённые значения остаются в форме, переход не выполняется; не закрывать приложение до успешной записи или фиксации ошибки.

Старые format1 черновики мигрируют по именованным полям с сохранением исходного registry archive. Повреждённый/неполный/неизвестный формат не очищается и блокирует запись этой формы. Текст, который прежняя версия не смогла записать из-за DefaultLazyKey и который уже исчез из RAM, из APK восстановить невозможно.

Безопасный возврат при сбое: прекратить использование тестового приложения, сохранить сообщение и файлы этой передачи. Рабочая установка остаётся отдельной. Не пытаться принудительно понизить versionCode3 до2 и не удалять/очищать тест ради возврата: обычный downgrade/совместимость нового draft format2 со старым APK не проверялись. Никаких команд ADB выполнять не нужно.
